# جمعية التنمية الزراعية بالعماير — الموقع الإلكتروني

الموقع الرسمي لجمعية التنمية الزراعية بالعماير، جمعية أهلية سعودية مرخصة برقم **1000612900** تعمل تحت إشراف وزارة البيئة والمياه والزراعة بمنطقة عسير.

## بنية الموقع

| الصفحة | الوصف |
|---|---|
| `index.html` | الرئيسية — التعريف بالجمعية والإحصاءات والبرامج |
| `about.html` | عن الجمعية — الرؤية والرسالة ومجلس الإدارة والهيكل التنظيمي وبيانات الترخيص |
| `programs.html` | البرامج والمشاريع — من الخطة التشغيلية للسنة الأولى |
| `governance.html` | الحوكمة والشفافية — مكتبة الوثائق (استعراض مباشر + تنزيل) |
| `contact.html` | تواصل معنا — بيانات التواصل والتبرع ونموذج المراسلة |

- `documents/` — ملفات الحوكمة (11 وثيقة PDF)
- `assets/` — الهوية البصرية (الشعار، الخطوط، CSS، JS)

## تقنياً

موقع ثابت (HTML/CSS/JS) عربي RTL بالكامل، بدون أي تبعيات خارجية — الخطوط والشعار مستضافة داخلياً. جاهز للنشر على GitHub Pages أو أي استضافة ثابتة.

### تشغيل محلي

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

### النشر على GitHub Pages

workflow النشر جاهز في `.github/workflows/pages.yml` ويعمل تلقائياً عند الدفع إلى `main`.
لتفعيله: إعدادات المستودع → **Pages** → Source: **GitHub Actions**.
